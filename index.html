01

太陽光発電システム販売

住宅用太陽光発電設備を中心に、 お客様の住環境や電力使用状況に合わせた 最適なシステムをご提案します。

02

蓄電池システム販売

太陽光で生み出した電力を有効活用し、 電気料金削減や災害時の備えにつながる 蓄電池システムをご提案します。

03

設計・提案サポート

商品を販売するだけではなく、 設計・施工・価格比較まで含めて、 お客様にとって最適な選択をサポートします。

02 / PHILOSOPHY

営業のあるべき姿を、 正します。

太陽光発電は高額な商品だからこそ、 お客様と販売側の間に情報格差が生まれやすい領域です。 山源は、その情報格差を利用するのではなく、 正しく伝え、納得して選んでいただくことを大切にします。

高額な中間マージン

多くの販売経路を経由することで、 商品そのもの以外のコストが積み上がる構造。

不透明な価格設定

同じような商品でも価格差が大きく、 お客様が適正価格を判断しにくい問題。

不要な商品提案

本当に必要かどうかより、 販売側の都合を優先した提案が行われるケース。

サポートの不足

契約後の相談やメンテナンスまで含めた 長期的なサポート体制の重要性。

03 / STRUCTURE REFORM

高いのは、商品ではなく、 販売構造だ。

CONVENTIONAL MODEL

従来の販売構造

メーカー → 一次代理店 → 二次代理店 → 営業会社 → 顧客

流通経路が増えるほど、 それぞれの工程でコストが発生します。

VS
SANGEN MODEL

山源の販売構造

メーカー → 山源 → 顧客

流通構造をシンプルにすることで、 不要なコストを削減し、 お客様への価格に還元することを目指します。
